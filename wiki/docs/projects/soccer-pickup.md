## How to Use

Soccer Pickup manages the weekly pickup game sign-up for Marietta, GA.

### For Players

1. Open [soccer.drewbefree.com](https://soccer.drewbefree.com)
2. The page shows this week's **game details**: date, time, location, and any notes from the admin
3. A **live weather forecast** for Marietta loads automatically — no guessing if it'll rain
4. If the game is on, enter your name and click **Sign Up**
5. Your name appears in the signup list immediately — no account needed

If the game is **cancelled**, a banner appears and the signup form is hidden.

### For the Admin

The admin panel is accessible with the shared admin password.

**Setting up a game:**
1. Click **Admin** and enter the password
2. Edit game details: date, time, location, and any notes (e.g., "bring pinnies")
3. Location autocomplete suggests previously used fields
4. Save — players see the update immediately

**Managing signups:**
- Remove individual signups if someone messages you they can't make it
- Use the **Game Cancelled** toggle to hide signups and show the cancellation banner

**After the game:**
- Signups auto-clear after the game date passes — no manual cleanup needed

### Sharing

Use the **Share** button to send the game link via your device's share sheet (or copy to clipboard). Send it to your group chat.

### Tips

- The weather is pulled from Open-Meteo for the Marietta coordinates — check it the morning of
- Location history saves previously used fields so you don't have to retype
- The cancelled banner is a quick toggle — flip it back on if the game is back on
