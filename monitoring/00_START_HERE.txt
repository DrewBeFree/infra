⚠️  CRITICAL FILE NAMING NOTE

When deploying, note:

- prometheus.yml in this package is PROMETHEUS SCRAPE CONFIG
  In ~/monitoring, name it: prometheus.yml (it goes in root)
  
- grafana-datasource.yml
  In ~/monitoring/grafana-provisioning/datasources/, rename to: prometheus.yml
  
This avoids conflicts. COPY_PASTE_DEPLOY.md shows exact paths.

🆘 TROUBLESHOOTING

If deployment fails:

1. Check Docker is installed on Atlas:
   docker --version
   docker-compose --version

2. Check file permissions:
   ls -la ~/monitoring/

3. Check container status:
   docker ps
   docker logs atlas-prometheus

4. Check Prometheus can scrape:
   curl http://localhost:9090/api/v1/targets

See MONITORING_DEPLOYMENT_GUIDE.md for detailed troubleshooting.
